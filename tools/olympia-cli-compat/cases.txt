# Argument-vector matrix for tools/olympia-cli-compat/run.sh.
#
# Fields, separated by whitespace (args is the rest of the line):
#   label   unique name; run directory is <number>-<label>
#   expect  same  Go must match C byte for byte: stdout, stderr, the two
#                 merged into one file (2>&1), and the exit status
#           nyi   the vector reaches a mode the port has not implemented:
#                 Go must exit nonzero with "not yet implemented" on stderr,
#                 and its stdout must be the start of C's
#   args    the argument vector after argv[0], split as bash words ('' is an
#           empty argument). Empty means no arguments.
#
# Every run starts in an empty directory with stdin from /dev/null and
# argv[0] set to olympia-g3.
