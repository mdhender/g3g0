# Fields, separated by whitespace (args is the rest of the line, split as
# bash words):
#   label   unique name; also the run directory
#   expect  ok    the reference must exit 0
#           fail  the reference must exit nonzero
#           help  the reference must exit 0 without writing files
#   group   cases in the same group must all produce different worlds, so a
#           port that ignored the seed cannot pass; "-" for none
#   setup   "-", or one of:
#             dir:NAME  create a directory NAME so fopen(NAME, "w") fails
#             ro        make the run directory read-only
#             posix     run with POSIXLY_CORRECT=1
#   args    the argument vector after argv[0]
#
# Every case runs the C reference twice and the Go port twice, each in a fresh
# empty directory with argv[0] set to genesis-g3.
