# Differential test cases for tools/island-compat/run.sh.
#
# Fields, separated by whitespace (stages is the rest of the line):
#   label   unique name; also the run directory
#   expect  ok    every reference stage must exit 0
#           fail  the last reference stage must exit nonzero
#   group   cases in the same group must all produce different output, so a
#           port that ignored the seed cannot pass; "-" for none
#   map     the input map (see make_map in run.sh):
#             fx:NAME           tests/island/fixtures/NAME
#             file:NAME         maps/NAME
#             gen:W:H:XX[:crlf] H rows of W copies of byte 0xXX
#             genesis:ARGS      the Map genesis-g3 writes for ARGS (commas
#                               stand for blanks)
#   seed    the starting randseed: fx:NAME, hex:BYTES (any length), none,
#           or dir (randseed is a directory)
#   setup   "-", or ro (randseed is read-only)
#   stages  island argument vectors after argv[0], separated by '|'; each
#           is split as bash words. Empty means one run with no arguments.
#
# Every case runs the C reference twice and the Go port twice, each in a fresh
# directory with argv[0] set to island-g3.
